Changelog

All notable changes to caddy-analyzer will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

0.6.1 — 2026-08-31

Added

  • GeoIP entry filters (#37): --country, --exclude-country, --asn, --exclude-asn filter log entries by GeoIP data. Supports both ISO codes (IT, US) and country names (Italy, United States). — @lenny-ts
  • Auto-download cosign (#62): caddy-analyze update now automatically downloads cosign for signature verification when not installed, removing the manual setup requirement. — @lenny-ts

Fixed

  • Guard output now shows blocklist/country-block bans (#83): blocklist and country-block bans were only logged to audit but not shown in terminal output. — @lenny-ts
  • Unblock idempotent: unban and guard expiry no longer fail with "partial unblock failures" when the iptables rule doesn't exist in one chain (hybrid mode). — @lenny-ts

0.6.0 — 2026-08-30

Added

  • Firewall backend redesign: multi-backend support (iptables, Docker DOCKER-USER, nftables, hybrid) with automatic environment detection. Guard now applies rules to both INPUT and DOCKER-USER chains when Docker containers are detected, solving the issue where blocked IPs bypassed the firewall in Dockerised Caddy deployments. — @lenny-ts
  • Whitelist command: caddy-analyze whitelist --add/--remove/--list/--init manages the never-block list. Auto-loaded by guard via /etc/caddy-analyzer/whitelist.txt. — @lenny-ts
  • Operational tuning flags (#56): --geo-cache-ttl, --geo-cache-size, --iptables-timeout replace compile-time constants. — @dchaudhari7177

Fixed

  • loadState does not recreate iptables rules (#79): on guard restart, loadState() restores IPs to the in-memory map but did not call blocker.Block() to recreate iptables rules. Banned IPs could pass through until the sliding window filled again. — @lenny-ts
  • Graceful shutdown: guard now flushes state and suppresses noisy "context canceled" errors on Ctrl+C. — @lenny-ts
  • Active filters not shown in report header (#51): --max-latency, --min-size, --max-size, --level, --ops-only were omitted from the "Filters:" line. — @dchaudhari7177
  • validateIP / validateIPOrCIDR duplication (#49): unified into a single validateIP. — @dchaudhari7177

Changed

  • Sigma rule UUIDs are now RFC 4122 version 5 (#59): MD5-based identifiers were not valid UUIDs. Now uses uuidV5 with a derived namespace, matching Sigma conventions. Rules exported before this release carry different UUIDs. — @dchaudhari7177
  • GitHub Actions SHA-pinned (#55): all third-party actions pinned to full commit SHAs. — @dchaudhari7177

0.5.1 — 2026-08-29

Fixed

  • Docker log monitoring (docker://) not capturing entries (#57): execLines only read stdout via StdoutPipe, but Caddy writes to stderr. Replaced with io.Pipe() merging both streams.

Changed

  • Deduplicate yamlEscape/yamlQuote: removed yamlQuote exact copy; call sites now call yamlEscape (#48).

Fixed (also in 0.5.1)

  • Zero-duration delta formatting: formatDurationDelta(0) now returns "N/A" via output.FormatDuration (#47).

Added

  • GeoIP entry filters (--country / --exclude-country / --asn / --exclude-asn) (#21): keep or drop entries by GeoIP. Requires mmdb.

Fixed

  • Enrich-before-filter order: entries are GeoIP-enriched before filtering when geo-based filters are active. Non-geo runs keep filter-first optimization.

0.5.0 — 2026-08-22

Added

  • update subcommand with cosign verification (#16): fail-closed keyless signature + SHA256, flags --check, --version, --force, --install-dir, Windows rename-aside handling.
  • Operational (non-HTTP) log support: level/logger/msg counts, Extra map, flags --level, --ops-only, 8th tab in watch.
  • Operational tab in --watch dashboard: key 8.
  • Sample log fixtures: testdata/sample.log (68 lines) and testdata/large.log (~50K lines) + testdata/generate.py.

Docs

  • docs/sources.html: Section 7 on fixtures.

0.4.1 — 2026-08-18

Fixed

  • Apparent freeze with no log source (#19): now prints clear error instead of blocking on stdin TTY; --watch refuses stdin.
  • --watch startup blocked on GeoIP download: now NewGeoIPAsync background.
  • Usage spam on source errors: SilenceUsage: true on root/tail/top/guard.
  • GeoIP search paths on Windows: os.UserHomeDir() instead of HOME (#27).
  • Follow/interval mode filters: applied before enrichment (#26).

Changed

  • TUI tab navigation: modulo arithmetic (#18).

0.4.0 — 2026-08-17

Added

  • Blocklist feed system: blocklist refresh/list/config/init with 7-day CIDR trie cache.
  • 8 default blocklist feeds: Spamhaus DROP v4/v6, FireHOL L1/2, CINS, Tor, ET, AbuseIPDB.
  • Guard blocklist integration: immediate block via CIDR trie; --no-blocklist, --blocklist-refresh 6h.
  • Guard country-block: --country-block CN,RU,IR with fail-fast mmdb check.
  • GeoIP enrichment: DB-IP/MaxMind mmdb with auto-download P3TERX mirror; --geoip-db, --no-auto-download.
  • top country / top asn: human-readable names.
  • --watch GeoIP tab: key 7 with background enrichment.
  • Documentation site: initial glassmorphism docs with TOC and Lighthouse optimizations.

Fixed

  • GeoIP download URLs: P3TERX mirror replacing dead download.dbip.com.
  • CINS Army URL: corrected.
  • Country codes shown instead of names: fixed.

Changed

  • AbuseIPDB enricher removed: only GeoIP mmdb remains.
  • Guard startup summary: now prints blocklist + country-block stats.
  • Go 1.25.13.

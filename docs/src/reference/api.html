API / Packages

Import path: github.com/lenny-ts/caddy-analyzer/pkg/*. Go 1.25+. For the data flow across these packages, see Architecture.

Examples are function-body excerpts; also import context, log, os and time where used. Supply the input entry, log channel or existing engine shown in each excerpt.

parser — Caddy JSON → Go structs

Parses one JSON line into *LogEntry (handled request) or *OperationalEntry (log without request).

import "github.com/lenny-ts/caddy-analyzer/pkg/parser"
import "github.com/lenny-ts/caddy-analyzer/pkg/types"

entry, err := parser.Parse(line)
if err != nil { log.Fatal(err) }
switch v := entry.(type) {
case *types.LogEntry:
    log.Print(v.Method, v.URI, v.Status)
case *types.OperationalEntry:
    log.Print(v.Level, v.Msg)
}
Key typeFields
LogEntryMethod, URI, Host, RemoteIP, Status, Size, Duration, UserAgent, Referer, ForwardedFor
OperationalEntryLevel, Logger, Msg, Extra map[string]json.RawMessage

analysis — filtering + 26-category detection

import "github.com/lenny-ts/caddy-analyzer/pkg/analysis"
import "github.com/lenny-ts/caddy-analyzer/pkg/types"

filters := types.Filters{From: time.Now().Add(-time.Hour), HasFrom: true, Status: []int{500}}
eng := analysis.New(filters)
det := analysis.NewDetector()
det.SetUARotationThreshold(10)
eng.SetDetector(det)

// per line:
if analysis.MatchEntry(entry, filters) {
    eng.Process(entry)     // counters + detector + histogram
}
eng.Finalize()
stats := eng.Stats()
topIPs := analysis.TopN(stats.RemoteIPCounts, 10)
suspicious := stats.SuspiciousIPs // grouped by IP with MITRE tags

Behavioral heuristics: ua_rotation ≥10, object_enumeration ≥10 IDs/template, beaconing CV<0.25. Export Sigma: det.ExportSigmaInfo().

enrich — GeoIP

import "github.com/lenny-ts/caddy-analyzer/pkg/enrich"

geo, err := enrich.NewGeoIP("") // auto-discovery and optional download
if err != nil { log.Fatal(err) }
defer geo.Close()
info, err := geo.Lookup("203.0.113.18") // -> CountryCode, CountryName, ASN
if err != nil { log.Fatal(err) }
code := enrich.CountryCodeFromName("Italy", geo.Path()) // "IT"

Cache: 50K LRU, 24h TTL (tunable via Configuration). Async variant: NewGeoIPAsync.

import "github.com/lenny-ts/caddy-analyzer/pkg/blocklist"

mgr, err := blocklist.NewManager(nil, ".cache/caddy-analyzer/blocklists")

guard — firewall

import "github.com/lenny-ts/caddy-analyzer/pkg/guard"
import "github.com/lenny-ts/caddy-analyzer/pkg/guard/firewall"

ctx := context.Background()
selfIPs, err := guard.DetectSelfIPs(ctx)
if err != nil { log.Fatal(err) }
backend := firewall.Detect(firewall.BackendAuto)
g := guard.New(guard.Config{
  Limit: 100, Window: time.Minute, BlockDuration: 10*time.Minute,
  EvalInterval: time.Second,
  FirewallBackend: backend, GeoIP: geo, BlocklistMgr: mgr,
  StatePath: "/var/lib/caddy-analyzer/blocked.json",
  NeverBlock: []string{"10.0.0.0/8"},
  NeverBlockFile: "whitelist.txt", NeverBlockRefresh: 30*time.Second,
  SelfIPs: selfIPs, SelfIPLookup: guard.DetectSelfIPs,
  OnError: func(err error) { log.Print(err) },
  OnAudit: func(action, ip, reason, duration string) {
    log.Printf("%s %s %s %s", action, ip, reason, duration)
  },
})
// linesCh is a <-chan string of raw Caddy JSON log lines.
g.Run(ctx, linesCh, log.Printf) // detection, ticks, expiry and 30s self-IP refresh
g.FlushState()

Also import context, log and time. Unlike the CLI default, library callers opt into self-IP protection by seeding SelfIPs before New restores state and setting SelfIPLookup. Leave both unset for explicit-whitelist-only operation. Evaluate(line string) returns no value; Tick(ctx) returns blocked candidates when driving the loop manually.

State persists to /var/lib/caddy-analyzer/blocked.json. See Architecture → data flow for where guard sits.

doctor — read-only diagnostics

doctor.Collect(doctor.Env{...}) returns grouped checks; doctor.NewReport(groups) computes severity counts and exit status. Render with WriteText(io.Writer) or WriteJSON(io.Writer); check returned errors and report.Summary.ExitCode. Supply the actual EUID, state/log/cache/GeoIP paths and runtime version in Env. Injectable command hooks permit tests without a live firewall. The CLI also adds shared configuration-validation failures to the report.

For optional authentication rules, use analysis.NewAuthAbuseDetector(cfg) and NewSession() for independent evidence storage; pass it as the optional second argument to analysis.NewDetectorWithPatterns or as guard.Config.AuthAbuse. See threshold and memory limits.

reader — multi-source ingestion

import "github.com/lenny-ts/caddy-analyzer/pkg/reader"

src := reader.ParseSource("docker://caddy")
r := reader.FromSourceFollow(src)
lines, err := r.Read(ctx)
if err != nil { log.Fatal(err) }
for line := range lines {
    entry, err := parser.Parse(line)
    if err != nil { log.Print(err); continue }
    // Process entry.
    _ = entry
}

Merges Docker stdout+stderr, follows file rotation via inode check, globs via expandPaths.

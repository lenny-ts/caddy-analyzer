API / Pacchetti

Gli esempi sono estratti da corpi di funzione: importa anche context, log, os e time dove usati, fornendo entry, canale log o engine indicati.

Percorso di importazione: github.com/lenny-ts/caddy-analyzer/pkg/*. Go 1.25+. Per il flusso dei dati attraverso questi pacchetti, consulta Architettura.

parser — JSON Caddy → struct Go

Analizza una riga JSON in *LogEntry (richiesta gestita) o *OperationalEntry (log senza request).

import "github.com/lenny-ts/caddy-analyzer/pkg/parser"
import "github.com/lenny-ts/caddy-analyzer/pkg/types"

entry, err := parser.Parse(line)
if err != nil { log.Fatal(err) }
switch v := entry.(type) {
case *types.LogEntry:
    log.Print(v.Method, v.URI, v.Status)
case *types.OperationalEntry:
    log.Print(v.Level, v.Msg)
}
Tipo chiaveCampi
LogEntryMethod, URI, Host, RemoteIP, Status, Size, Duration, UserAgent, Referer, ForwardedFor
OperationalEntryLevel, Logger, Msg, Extra map[string]json.RawMessage

analysis — filtraggio + rilevamento in 26 categorie

import "github.com/lenny-ts/caddy-analyzer/pkg/analysis"
import "github.com/lenny-ts/caddy-analyzer/pkg/types"

filters := types.Filters{From: time.Now().Add(-time.Hour), HasFrom: true, Status: []int{500}}
eng := analysis.New(filters)
det := analysis.NewDetector()
det.SetUARotationThreshold(10)
eng.SetDetector(det)

// per line:
if analysis.MatchEntry(entry, filters) {
    eng.Process(entry)     // counters + detector + histogram
}
eng.Finalize()
stats := eng.Stats()
topIPs := analysis.TopN(stats.RemoteIPCounts, 10)
suspicious := stats.SuspiciousIPs // grouped by IP with MITRE tags

Euristiche comportamentali: ua_rotation ≥10, object_enumeration ≥10 IDs/template, beaconing CV<0.25. Esporta Sigma: det.ExportSigmaInfo().

enrich — GeoIP

import "github.com/lenny-ts/caddy-analyzer/pkg/enrich"

geo, err := enrich.NewGeoIP("") // auto-discovery and optional download
if err != nil { log.Fatal(err) }
defer geo.Close()
info, err := geo.Lookup("203.0.113.18") // -> CountryCode, CountryName, ASN
if err != nil { log.Fatal(err) }
code := enrich.CountryCodeFromName("Italy", geo.Path()) // "IT"

Cache: 50K LRU, TTL 24h (configurabile tramite Configurazione). Variante asincrona: NewGeoIPAsync.

guard — firewall

import "github.com/lenny-ts/caddy-analyzer/pkg/guard"
import "github.com/lenny-ts/caddy-analyzer/pkg/guard/firewall"

ctx := context.Background()
selfIPs, err := guard.DetectSelfIPs(ctx)
if err != nil { log.Fatal(err) }
backend := firewall.Detect(firewall.BackendAuto)
g := guard.New(guard.Config{
  Limit: 100, Window: time.Minute, BlockDuration: 10*time.Minute,
  EvalInterval: time.Second,
  FirewallBackend: backend, GeoIP: geo, BlocklistMgr: mgr,
  StatePath: "/var/lib/caddy-analyzer/blocked.json",
  NeverBlock: []string{"10.0.0.0/8"},
  NeverBlockFile: "whitelist.txt", NeverBlockRefresh: 30*time.Second,
  SelfIPs: selfIPs, SelfIPLookup: guard.DetectSelfIPs,
  OnError: func(err error) { log.Print(err) },
  OnAudit: func(action, ip, reason, duration string) {
    log.Printf("%s %s %s %s", action, ip, reason, duration)
  },
})
// linesCh è un <-chan string di righe JSON Caddy grezze.
g.Run(ctx, linesCh, log.Printf) // rilevamento, tick, scadenze e aggiornamento IP ogni 30s
g.FlushState()

Importa anche context, log e time. Diversamente dal default CLI, chi usa la libreria abilita la protezione inizializzando SelfIPs prima che New recuperi lo stato e impostando SelfIPLookup. Lascia entrambi vuoti per usare solo la whitelist esplicita. Evaluate(line string) non restituisce valori; Tick(ctx) restituisce i candidati bloccati se gestisci il ciclo manualmente.

Lo stato persiste in /var/lib/caddy-analyzer/blocked.json. Consulta Architettura → flusso dei dati per vedere dove si colloca guard.

doctor — diagnostica in sola lettura

doctor.Collect(doctor.Env{...}) restituisce i controlli raggruppati; doctor.NewReport(groups) calcola conteggi e codice di uscita. Usa WriteText(io.Writer) o WriteJSON(io.Writer), verificando gli errori e report.Summary.ExitCode. Passa EUID reale, versione e percorsi di stato/log/cache/GeoIP in Env. Gli hook dei comandi consentono test senza firewall attivo. La CLI aggiunge anche gli errori della validazione condivisa della configurazione.

Per le regole opzionali di autenticazione usa analysis.NewAuthAbuseDetector(cfg) e NewSession() per evidenze indipendenti; passa il risultato come secondo argomento opzionale di analysis.NewDetectorWithPatterns o in guard.Config.AuthAbuse. Consulta soglie e limiti di memoria.

    if err != nil { log.Print(err); continue }

    _ = entry
}

Unisce stdout+stderr di Docker, segue la rotazione dei file tramite controllo inode, espande i glob tramite expandPaths.

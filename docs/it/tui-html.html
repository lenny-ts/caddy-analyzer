Report TUI e HTML

Due modi per visualizzare risultati live o condivisibili. Parti da Avvio rapido → passaggio 5; flag in Riferimento CLI.

TUI — dashboard live (--watch)

caddy-analyze --watch /var/log/caddy/access.log
caddy-analyze --watch docker://caddy
caddy-analyze --watch --detect /var/log/caddy/access.log  # with security tab

Tasti: 1–8 cambia scheda, Tab/Shift+Tab scorrono, r reimposta la finestra, q esce. Reimpostazione automatica ogni 5 min.

SchedaMostra
1 RiepilogoPeriodo, RPS, barre 2xx/3xx/4xx/5xx, byte, P50/P95/P99, umani/bot
2 Tempo realeStream colorato (ultimi 15)
3 SicurezzaPrimi 15 IP sospetti con confidenza e tecniche (richiede --detect)
4 IP principaliPrimi 20 IP per richieste
5 Percorsi principaliPrimi 20 percorsi
6 User agentPrimi 15 UA
7 GeoPrimi 15 paesi + primi 15 ASN (richiede GeoIP; suggerimento di download in background se in attesa)
8 OperativoConteggi livello/logger/messaggio + ultimi 15 eventi operativi (richiede --level o log misto)

Combina con i filtri globali: caddy-analyze --watch --from 1h --country IT --no-bots --detect. Flag: --watch e solo root; si applicano comunque flag persistenti come --top/--format.

Report HTML — autonomo

caddy-analyze -f html -o report.html --detect testdata/sample.log
caddy-analyze -f html -o report.html --detect /var/log/caddy/access.log
xdg-open report.html  # or open / start

Singolo file scuro, nessun server, nessuna risorsa esterna, sicuro con html.EscapeString. Disponibili anche -f json/-f csv (-o scrive con 0600):

caddy-analyze -f json -o report.json --detect /var/log/caddy/access.log
caddy-analyze -f csv -o report.csv /var/log/caddy/access.log

Anteprima

La demo e l'output del formatter HTML (stesso CSS dei report). CLI completa per i formati: Riferimento CLI → Output e Guida → Utilizzo → Formati.

Architettura

Singolo binario, zero CGO, memoria limitata (LRU + istogramma). Per le firme dei pacchetti e gli esempi di importazione, consulta API / Pacchetti. Per aggiungere una funzionalita, consulta Contribuire.

Limiti di memoria

MaxCardinality 100k per contatore, LRU IP da 100k, istogramma da 1000 bucket (log10, 1µs–10s), LRU GeoIP da 50k. Nessuna mappa senza limiti.

Flusso di configurazione

caddy-analyzer.json (locale → globale) → PersistentPreRunE applyTuning() → override dei flag CLI. Guard aggiunge l'unione di whitelist + --never-block. Consulta Configurazione.

Vedi anche
API / Pacchetti — importazione e uso per pacchetto. Contribuire — dove aggiungere un rilevamento (pkg/analysis/detect.go), un feed (pkg/blocklist) o un backend firewall (pkg/guard/firewall).

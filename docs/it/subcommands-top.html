top

Ispettore classificato. sola lettura — non modifica mai il sistema.

Sintassi

caddy-analyze top [dimension] [source...] [flags]
caddy-analyze top -b <dimension> [source...]   # --by alias

La dimensione predefinita è path se omessa.

Flag

FlagBrevePredefinitoDescrizione
--by-bAlias della dimensione per l'argomento posizionale
--top-t10Numero massimo di voci (anche --top globale)

Eredita tutti i flag globali (--from, --country, --5xx, --format ecc. — consulta Riferimento CLI).

Dimensioni

DimensioneRichiede GeoIPDescrizione
pathPercorsi più richiesti
ipIP client principali
uaUser agent principali
statusCodici di stato principali
methodMetodi HTTP principali
hostHost principali
bandwidthPrimi per dimensione della risposta
countrysìPaesi principali (nomi leggibili)
asnsìASN principali

Esempio minimo

sola lettura

caddy-analyze top ip testdata/sample.log
caddy-analyze top path -t 20 testdata/sample.log
caddy-analyze top country testdata/sample.log

Esempio avanzato

sola lettura — filtrato, formattato, output su file.

caddy-analyze top path --5xx -t 20 -f csv -o top-5xx.csv testdata/sample.log
caddy-analyze top ip --from 1h --country IT -t 15 -f json testdata/large.log | jq
caddy-analyze top asn --no-bots --from 7d /var/log/caddy/access.log -f csv -o top-asn.csv

Log JSON di Caddy,
finalmente leggibili e protetti.

Caddy v2 scrive log JSON annidati (request.uri, status, tls, headers), non Common Log Format. grep, goaccess e lnav non li interpretano correttamente. caddy-analyzer li analizza nativamente, classifica il traffico e segnala gli attacchi con un motore a doppio passaggio e 26 categorie.

Inizia in 60 secondi → GitHub
caddy-analyzer --detect /var/log/caddy/access.log
